What is an amplifier?

An amplifer is a device that takes in an input signal and gives out a signal with an increased magnitude. For instance consider a microphone, the input to the mic is our speech signal which is a few millivolts in magnitude. The mic has an inbuilt amplifier which raises the magnitude of speech signal which is hen ta=ransmitted via an antenna to the rest of the room. In this article we're going to undertand the priciple and structure of the amplifier, specifically a voltage amplifier.

Building an amplifier

Now let is try to build out own amplifier i.e. take an input voltage and return an output voltage. The amplifier black box can be modelled as a current source, therefore by connecting a load across it we can measure the output voltage. The black box is modelled as a VCCS

Now where fo we go for this diamond device i.e. VCCS? This is what a BJT is. The BJT is essentially a current source which depends on input voltage. So the black box that was modelled as a current source can be represented using a BJT.

A very brief intro to Diodes

Diode consists of a p-type and an n-type semiconductors arranged side by side. Due to this arrangement, the electrons and holes from both sides combine at the juction. This junction is called the depletion region. A diode consists of tow currents: diffusion and drift current.

  • Diffusion current: movement of majority charged carriers due to the concetration gradient across the junction.
  • Drift current: movement of minorit charged carriers due to electric field at the junction.
Diode (PN Junction)

A diode without any potential have both drift and diffusion currents of the same magnitude but opposite directions. But, if there was a potential applied across the diode, there are two possible configurations: (a) Forward-bias, (b) Reverse-bias

In forward-bias, depletion region decreases which in turn allows electrons to flow across the junction.

Operation of a voltage amplifier

h

A voltage amplifier is a voltage dependent current source. Here, the current source depends on the input voltage (I = k * Vin). This current passes through a load resistor through which the output voltage can be measured. 

                                            Vout = Rl * I
                                                 = Rl * K * Vin

From the formula above, we can tell that the input voltage gets amplified. But what device acts as an voltage dependent current source? This is where a BJT comes in handy.

Structure of BJT

In an NPN transistor, one p-type semiconductor is sandwiched between two n-type semiconductors and they are labeled as emitter (n-type), base (p-type) and collector (n-type).

The emitter is heavily doped with electrons, base is lightly doped and very thin and the collector is the largest amoung the three.
